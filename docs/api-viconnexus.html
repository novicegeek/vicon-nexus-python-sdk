ViconNexus

Connection & session

__init__(host='localhost')Control

Constructor. Creates the underlying ViconNexusClient and immediately attempts to connect to the host application.

ParameterTypeDescription
hoststrHostname or IP address of the machine running Nexus; defaults to localhost.

Returns the instance. Raises IOError("Unable to connect to Nexus") if the connection fails. Side effect sets self.GenerateErrors = True.

vicon = ViconNexus.ViconNexus()
# On connection failure:
# IOError: Unable to connect to Nexus

Connect(host='localhost')Control

Reconnects if not currently connected; does nothing when already connected. Use it to recover from a transient network drop without rebuilding the object.

ParameterTypeDescription
hoststrHost to connect to; only used while disconnected.

Returns None. Raises IOError if reconnection fails.

if not vicon.IsConnected():
    vicon.Connect()

Disconnect()Control

Disconnects from the host application. A no-op when already disconnected.

vicon.Disconnect()

IsConnected()Read

Queries whether the connection to the host is currently alive.

Returns bool.

vicon.IsConnected()   # True / False

GetServerInfo()Read

Returns version information for the connected server (host), useful for checking that the SDK and Nexus versions match.

Returns (program, major, minor, point, release_type) — program is the program name (str), major/minor/point are int version numbers, and release_type is a release-type string (str).

program, major, minor, point, rel = vicon.GetServerInfo()
if (major, minor) != (2, 12):
    print('Version mismatch:', program, major, minor, point, rel)

Unlabeled trajectories

Unlabeled trajectories are point clusters that have been reconstructed but not yet assigned to a subject marker. Their indices and ordering are determined by Nexus and are not stable across trials — do not cache indices between loads.

GetUnlabeledCount()Read

Number of unlabeled trajectories.

Returns int.

n = vicon.GetUnlabeledCount()

GetUnlabeled(index)Read

Reads every frame of one unlabeled trajectory by index.

ParameterTypeDescription
indexintTrajectory index in the range 0 … GetUnlabeledCount()-1.

Returns (x, y, z, e) — three list[float] values (mm) and one list[bool].

x, y, z, e = vicon.GetUnlabeled(0)
if e[49]:
    print('Frame 50:', x[49], y[49], z[49])

Checks whether the marker has associated trajectory data (a marker can exist with no trajectory at all).

Returns bool.

    print(vicon.GetTrajectory('Colin', 'C7')[0][0])

GetTrajectory(subject, marker)Read

Reads trajectory data for every frame of the specified marker.

ParameterTypeDescription
subjectstrSubject name.
markerstrMarker name.

Returns (x, y, z, e) — three list[float] values and one list[bool]; length = frame count.

SetTrajectory(subject, marker, x, y, z, e)Write

Writes trajectory data for every frame of the specified marker.

If any of x/y/z is NaN for a frame, the SDK zeroes that frame's coordinates and sets e[i] to False before writing (i.e. it automatically "fills gaps" in the transport layer), so the lists you pass in are modified in place.

ParameterTypeDescription
subjectstrSubject name.
markerstrMarker name.
x, y, zlist[float]Coordinates (mm); length must equal the frame count.
elist[bool]Per-frame existence flag; False means no data at that frame (a gap).
 
frames = vicon.GetFrameCount()
vicon.SetTrajectory('Colin', 'C7', [0.0] * frames, [0.0] * frames,
                    [0.0] * frames, [True] * frames)

GetTrajectoryAtFrame(subject, marker, frame)Read

Reads one frame of trajectory data (cheaper in memory than reading the whole trajectory when looping frame by frame, but it incurs more round trips).

ParameterTypeDescription
subjectstrSubject name.
markerstrMarker name.
frameintFrame number as shown on the application time bar, 1-based.

Returns (x, y, z, e) — three float values and one bool.

x, y, z, e = vicon.GetTrajectoryAtFrame('Colin', 'C7', 50)

SetTrajectoryAtFrame(subject, marker, frame, x, y, z, e)Write

Writes a single frame of trajectory data. If any coordinate is NaN, e=False is set automatically and the coordinates are zeroed.

ParameterTypeDescription
frameintFrame number, 1-based.
x, y, zfloatCoordinates (mm).
eboolWhether data exists at this frame.

# When filling frame by frame, watch performance: use SetTrajectory for large batches
for frame in range(start, end + 1):
    vicon.SetTrajectoryAtFrame('Colin', 'C7', frame, x, y, z, True)

Segments & joints

Segments make up the subject's hierarchical skeleton; the root segment's parent is named 'World'. A joint connects two adjacent segments. This part of the API is read-only; to write the skeleton, use model outputs (for example the Plug-in Gait Bones group).

GetSegmentNames(subject)Read

List of the subject's segment names.

Returns list[str].

segments = vicon.GetSegmentNames('Colin')

GetRootSegment(subject)Read

Returns the name of the root segment (usually the pelvis).

Returns str.

root = vicon.GetRootSegment('Colin')
parent, children, markers = vicon.GetSegmentDetails('Colin', root)
print('Root segment parent:', parent)     # 'World'

GetSegmentDetails(subject, segment)Read

Hierarchy and association information for a segment.

ParameterTypeDescription
subjectstrSubject name.
segmentstrName of an existing segment on this subject.

Returns (parent, children, markers) — parent is the parent segment name (the root segment's parent is 'World'), children is a list[str] of child segment names, and markers is a list[str] of marker names associated with the segment.

parent, children, markers = vicon.GetSegmentDetails('Colin', 'LHip')
for child in children:
    print(child)

GetJointNames(subject)Read

List of the subject's joint names.

Returns list[str].

Names of the segments on either side of a joint.

ParameterTypeDescription
subjectstrSubject name.
jointstrName of an existing joint on this subject.

Returns (parent, child) — two str values.

parent, child = vicon.GetJointDetails('Colin', joints[0])

Model outputs

Model outputs are the general-purpose containers for "computed results" in Nexus: angles, forces, moments, power, Plug-in Gait bones and modeled markers are all model outputs. Each output has a group name (such as Angles, Forces, Plug-in Gait Bones, Modeled Markers), plus a number of "components", each of which carries a quantity type.

Valid quantity types (Quantity Type)Description
Length Mass Angle Acceleration Angular Acceleration Angular Velocity Frequency Force ForceNormalized Torque TorqueNormalized Power PowerNormalized Pressure Electric Potential Velocity Case-sensitive; passing any other string fails (the error is printed to stderr).

GetModelOutputNames(subject)Read

Names of all model outputs for the subject.

Returns list[str].

outputs = vicon.GetModelOutputNames('Colin')

GetModelOutputDetails(subject, modelOutputName)Read

The model output's group, component names and the quantity type of each component; useful for creating a new output with the same structure.

Returns (group, components, types) — group is the group name (str), and components and types are equally long list[str] values.

group, comps, types = vicon.GetModelOutputDetails('Colin', 'LeftHipAngle')
vicon.CreateModelOutput('Colin', 'MyCopy', group, comps, types)

GetModelOutput(subject, modelOutputName)Read

Reads data for every frame of a model output.

Returns (components, e) — components is an N×M nested list (N = number of components, M = frame count), and e is a list[bool] of length M giving per-frame existence. Values for missing frames are not guaranteed to be meaningful; filter with e first.

data, exists = vicon.GetModelOutput('Colin', 'LeftHipAngle')
n_components = len(data)        # e.g. 3 (X/Y/Z)
n_frames = len(data[0])         # equals GetFrameCount()
# value of component 2 at frame 50
print(data[1][49], exists[49])

SetModelOutput(subject, modelOutputName, components, e)Write

Writes data for every frame of a model output.

Internally it replaces NaN with 0 and sets the corresponding frame's exists to False; it also performs a compatibility conversion from numpy.bool_ to bool, so passing numpy arrays is safe.

ParameterTypeDescription
componentslist[list[float]]An N×M matrix: rows are components, columns are frames.
elist[bool]Per-frame existence of length M.
 
data, exists = vicon.GetModelOutput('Colin', 'LeftHipAngle')
vicon.SetModelOutput('Colin', 'MyCopy', data, exists)

# Zero everything
frames = vicon.GetFrameCount()
vicon.SetModelOutput('Colin', 'MyCopy', [[0.0] * frames for _ in range(3)],
                     [True] * frames)

GetModelOutputAtFrame(subject, modelOutputName, frame)Read

Reads the component values of a model output for a single frame.

Returns (components, e) — components is a list[float] of length N, and e is a bool.

comps, ok = vicon.GetModelOutputAtFrame('Colin', 'LeftHipAngle', 50)

SetModelOutputAtFrame(subject, modelOutputName, frame, components, e)Write

Writes a single frame of a model output. If any component is NaN, the whole frame is marked as non-existent and the components are zeroed.

ParameterTypeDescription
frameintFrame number, 1-based.
componentslist[float]Length must equal the number of components in this output.
eboolWhether data exists at this frame.
 
comps, ok = vicon.GetModelOutputAtFrame('Colin', 'LeftHipAngle', 50)
comps = [c + 100.0 for c in comps]
vicon.SetModelOutputAtFrame('Colin', 'LeftHipAngle', 50, comps, True)

CreateModelOutput(subject, modelOutputName, groupName, componentNames, QuantityTypes)Write

Creates a new model output (with no data yet); then fill it with SetModelOutput / SetModelOutputAtFrame. The name must be unique within the subject.

ParameterTypeDescription
groupNamestrGroup name; determines placement in the Nexus tree and may be customized.
componentNameslist[str]Component names; their count is the number of components.
QuantityTypeslist[str]Quantity type of each component (see the table above); length must match the component count.
 
names = ['RX', 'RY', 'RZ', 'TX', 'TY', 'TZ', 'SX', 'SY', 'SZ']
types = ['Angle', 'Angle', 'Angle',
         'Length', 'Length', 'Length',
         'Length', 'Length', 'Length']
vicon.CreateModelOutput('Colin', 'HED', 'Plug-in Gait Bones', names, types)
Complete Gait output To create the full set of Plug-in Gait outputs in one call, use ViconUtils.CreateViconGaitModelOutputs directly.

CreateModeledMarker(subject, modelOutputName)Write

Creates a "modeled marker": essentially a model output with group Modeled Markers, components X/Y/Z and quantity type Length. It is displayed in the workspace in 3D and can be read like a point; commonly used for midpoints, virtual markers and geometrically derived points.

Returns None. Then use GetModelOutput to fetch the N×M data and write it back.

vicon.CreateModeledMarker('Colin', 'MyMidpoint')

ax, ay, az, ae = vicon.GetTrajectory('Colin', 'RKNE')
bx, by, bz, be = vicon.GetTrajectory('Colin', 'RANK')

data, exists = vicon.GetModelOutput('Colin', 'MyMidpoint')
for i in range(vicon.GetFrameCount()):
    if ae[i] and be[i]:
        exists[i] = True
        data[0][i] = (ax[i] + bx[i]) / 2.0
        data[1][i] = (ay[i] + by[i]) / 2.0
        data[2][i] = (az[i] + bz[i]) / 2.0
    else:
        exists[i] = False
vicon.SetModelOutput('Colin', 'MyMidpoint', data, exists)

Subject & analysis parameters

Nexus has two kinds of "scalar parameter", both attached to a subject:

  • Subject parameters (subject parameter): static values such as height, weight and leg length. They have a unit, a default value and a "required" flag.
  • Analysis parameters (analysis parameter): values produced during analysis; readable and writable at any time.

Subject parameters

Names of all static parameters for the subject.

Returns list[str].

GetSubjectParamDetails(subject, param)Read

Gets a parameter's current value, unit, default value, required flag and has-value flag in one call.

Returns a 5-tuple (value, unit, default, required, hasvalue) — value/default are float, unit is str, and required/hasvalue are bool.

value, unit, default, required, hasvalue = \
    vicon.GetSubjectParamDetails('Colin', 'Height')
print('{0} [{1}] default {2}  required={3} has value={4}'.format(
    value, unit, default, required, hasvalue))

Events

Events are annotations of "frame number + intra-frame offset", such as foot strike/foot off. They are located by a triple: subject + context + event type.

FieldValid values (case-sensitive)
contextLeft, Right, General
eventFoot Strike, Foot Off, General
offsetIntra-frame offset (seconds), range 0.0 … 1/FrameRate

GetEvents(subject, context, event)Read

Queries all events matching the specified subject, context and event type.

Returns (frames, offsets) — list[int] and list[float], equally long; two empty lists when nothing matches.

frames, offsets = vicon.GetEvents('Colin', 'Left', 'Foot Strike')
for f, off in zip(frames, offsets):
    print('Frame {0} + {1:.4f}s'.format(f, off))

CreateAnEvent(subject, context, event, frame, offset)Write

Creates an event at frame + offset.

ParameterTypeDescription
contextstrLeft / Right / General.
eventstrFoot Strike / Foot Off / General.
frameintFrame number, 1-based.
offsetfloatIntra-frame offset in seconds, typically < 1/FrameRate.
 
vicon.ClearAllEvents()
vicon.CreateAnEvent('Colin', 'Left', 'Foot Strike', 137, 0.0)
vicon.CreateAnEvent('Colin', 'Left', 'Foot Off', 190, 0.006)
Parameter-order trap The source docstring example swaps context and event (vicon.CreateAnEvent('Patricia', 'Foot Strike', 'Left', ...)). The correct order is subject, context, event; see the code above.

ClearAllEvents()Write

Deletes all events in the current trial (all subjects, all contexts). This cannot be undone, and it does not affect older files already saved to disk.

vicon.ClearAllEvents()

Analog devices

Force plates, eye trackers and analog capture cards are all called device in the SDK. The hierarchy has three levels: 

DeviceID  ──▶  DeviceOutputID  ──▶  ChannelID
(one force plate)    (Force / CoP / Moment)   (Fx / Fy / Fz …)

Communication always uses IDs; names are optional convenience labels and are case-sensitive. A device's sampling rate may differ from the trial frame rate: if the device is faster, one frame corresponds to multiple samples, with samples ordered frame1[s1], frame1[s2], … frameN[sN].

GetDeviceIDs()Read

List of IDs of all analog devices in the trial.

Returns list[int] (unsigned integers).

for device_id in vicon.GetDeviceIDs():
    print(device_id, vicon.GetDeviceDetails(device_id)[:3])

GetDeviceNames()Read

List of names of devices that have names (unnamed devices are not included).

Returns list[str].

Looks up a device ID by device name.

ParameterTypeDescription

Returns the device ID (integer). If the name does not exist, returns 0/an invalid value and does not raise.

GetDeviceDetails(deviceID)Read

Device-level information, plus geometry and pose data for force plates and eye trackers.

Returns a 6-tuple (name, device_type, rate, deviceOutputIDs, forceplate, eyetracker):

ElementTypeDescription

device_typestr'ForcePlate' / 'EyeTracker' / 'Other'.
ratefloatDevice sampling rate (Hz).
deviceOutputIDslist[int]List of output IDs for this device.

eyetrackerNexusEyeTrackerAlways returned; only meaningful for eye trackers.

Device channel data

The six read methods combine two dimensions: local / global coordinates, and whole channel / single frame / "aligned to an optical frame".

Coordinate systemWhole channelSingle frame (sample frame number)Single optical frame (aligned)
Local (relative to the device) GetDeviceChannel GetDeviceChannelAtFrame GetDeviceChannelForFrame
Global (world coordinates) GetDeviceChannelGlobal GetDeviceChannelGlobalAtFrame GetDeviceChannelGlobalForFrame
AtFrame vs. ForFrame …AtFrame indexes by device sample frame; …ForFrame indexes by optical frame and returns the group of samples corresponding to that optical frame. For biomechanical analysis and alignment with markers, use Global + ForFrame.

GetDeviceChannel(deviceID, deviceOutputID, channelID)Read

Reads the whole channel (local coordinates).

Returns (channelData, ready, rate) — channelData is a list[float], length = frame count × samples per frame; ready is a bool; rate is a float (Hz).

data, ready, rate = vicon.GetDeviceChannel(plate_id, force_out, fx_id)

GetDeviceChannelAtFrame(deviceID, deviceOutputID, channelID, frame)Read

Reads all samples for a device sample frame by frame number.

Returns (channelData, ready, rate) — channelData length = samples per frame.

samples, ready, rate = vicon.GetDeviceChannelAtFrame(plate_id, force_out, fx_id, 200)

GetDeviceChannelForFrame(deviceID, deviceOutputID, channelID, frame)Read

Reads the sample data corresponding to an optical frame.

Returns (channelData, ready, rate).

# Same time base as the markers
samples, ready, rate = vicon.GetDeviceChannelForFrame(plate_id, force_out, fx_id, 200)

GetDeviceChannelGlobal(deviceID, deviceOutputID, channelID)Read

Reads the whole channel and transforms coordinates/directions into the world coordinate system. Only this version is physically meaningful for forces, moments and CoP.

Returns (channelData, ready, rate).

fz, ready, rate = vicon.GetDeviceChannelGlobal(plate_id, force_out, fz_id)

GetDeviceChannelGlobalAtFrame(deviceID, deviceOutputID, channelID, frame)Read

Reads samples in global coordinates by device sample frame number.

Returns (channelData, ready, rate).

GetDeviceChannelGlobalForFrame(deviceID, deviceOutputID, channelID, frame)Read

Reads samples in global coordinates by optical frame.

Returns (channelData, ready, rate).

SetDeviceChannel(deviceID, deviceOutputID, channelID, channelData)Write

Writes the whole channel. Use this method for bulk edits; it is much faster than frame-by-frame calls.

Frames marked as "missing" in the raw capture cannot be written: they read as 0 and writes to them are ignored, but channelData must still cover every sample.

ParameterTypeDescription
channelDatalist[float]Length = frame count × samples per frame.
 
import math

for device_id in vicon.GetDeviceIDs():
    name, dtype, rate, out_ids, plate, et = vicon.GetDeviceDetails(device_id)
    if dtype != 'ForcePlate':
        continue
    force_out = vicon.GetDeviceOutputIDFromName(device_id, 'Force')
    _, _, _, _, _, ch = vicon.GetDeviceOutputDetails(device_id, force_out)
    fx = vicon.GetDeviceChannel(device_id, force_out, ch[0])[0]
    fy = vicon.GetDeviceChannel(device_id, force_out, ch[1])[0]
    fz = vicon.GetDeviceChannel(device_id, force_out, ch[2])[0]

    # Treat anything below 25 N as noise and zero it
    mag = [math.sqrt(a * a + b * b + c * c) for a, b, c in zip(fx, fy, fz)]
    for i, m in enumerate(mag):
        if m < 25.0:
            fx[i] = fy[i] = fz[i] = 0.0

    vicon.SetDeviceChannel(device_id, force_out, ch[0], fx)
    vicon.SetDeviceChannel(device_id, force_out, ch[1], fy)
    vicon.SetDeviceChannel(device_id, force_out, ch[2], fz)

SetDeviceChannelAtFrame(deviceID, deviceOutputID, channelID, frame, channelData)Write

Writes the single-channel samples for one frame (length = samples per frame).

Performance The source explicitly warns that frame-by-frame calls can be significantly slower than one SetDeviceChannel. Prefer whole-channel writes for bulk edits. 
fx, _, _ = vicon.GetDeviceChannelAtFrame(plate_id, force_out, fx_id, 200)
fx = [v / 2.0 for v in fx]
vicon.SetDeviceChannelAtFrame(plate_id, force_out, fx_id, 200, fx)

Spline

The spline interface is for smooth differentiation of discrete trajectories: first submit valid scattered points to the spline object, then request the 1st (velocity) or 2nd (acceleration) derivative as needed. A ViconNexus instance has only one spline object, and each new submission overwrites the previous one.

SubmitSplineTrajectory(frames, xData, yData, zData, frameRate)Write

Initializes (or reinitializes) the spline object with scattered points. Submit only valid points: frames with gaps will corrupt the fit, so filter by e first.

ParameterTypeDescription
frameslist[int]Frame numbers of the scattered points (1-based).
xData, yData, zDatalist[float]Coordinates (mm); length must match frames.
frameRatefloatData frame rate (Hz), used for the time base when computing derivatives.
 
frame_rate = vicon.GetFrameRate()
start, end = vicon.GetTrialRange()
frames = list(range(start, end + 1))

x, y, z, e = vicon.GetTrajectory('Colin', 'LKNE')
valid = [i for i, ok in enumerate(e) if ok]

vicon.SubmitSplineTrajectory(
    [frames[i] for i in valid],
    [x[i] for i in valid],
    [y[i] for i in valid],
    [z[i] for i in valid],
    frame_rate)

vx, vy, vz = vicon.GetSplineResults(1)      # velocity
ax, ay, az = vicon.GetSplineResults(2)      # acceleration

GetSplineResults(derivative)Read

Gets the requested derivative order from the current spline object.

ParameterTypeDescription
derivativeintDerivative order: 1 = velocity, 2 = acceleration.

Returns (x, y, z) — three list[float] values with the same length as the number of submitted points.

Incorrect docstring The GetSplineResults docstring lists frames/x/y/z/frameRate again (copied from SubmitSplineTrajectory); the method actually takes only one parameter, derivative.

Trial operations

These four methods let an external Python process act as a remote control for Nexus. They cannot be called from a script running inside Nexus, or they will deadlock or fail outright.

RunPipeline(pipeline, location, timeout)Host

Runs a Nexus Processing Pipeline. If a pipeline is already running, this call fails.

ParameterTypeDescription
pipelinestrName of an existing pipeline.
locationstrPipeline location: 'Private', 'Shared', 'System'; pass an empty string '' to use the default search.
timeoutintClient-side timeout in seconds. A timeout only makes the client return early; the host pipeline keeps running.
 
vicon.RunPipeline('Reconstruct', '', 45)
vicon.RunPipeline('MyLabeling', 'Private', 120)

OpenTrial(trial, timeout)Host

Opens a trial in the host. Failure conditions: a pipeline is running, Nexus is in live mode, the corresponding .ENF file cannot be found, or the host currently disallows opening.

ParameterTypeDescription
trialstrAbsolute path to the trial, without the extension.
timeoutintClient-side timeout in seconds.
 
vicon.CloseTrial(30)
vicon.OpenTrial(r'C:\Users\Public\Documents\Vicon\Nexus Sample Data'
                r'\Colin\Walking Trials\Walking 2', 30)
Unsaved data triggers a dialog If the current trial has unsaved changes, the host's save prompt will block automation. Call SaveTrial() or CloseTrial() before batch processing.

SaveTrial(timeout)Host

Saves the current trial to disk. Fails while a pipeline is running or in live mode.

ParameterTypeDescription
timeoutintClient-side timeout in seconds.
 
vicon.SaveTrial(30)

CloseTrial(timeout)Host

Closes the current trial without saving. Fails while a pipeline is running or in live mode.

ParameterTypeDescription
timeoutintClient-side timeout in seconds.

Exceptions & switches

ViconNexusException(message, additional='')Exception

viconnexusapi.ViconNexus.ViconNexusException, derived from Exception. It is designed to represent SDK errors, but in the current 1.0.3 release the public methods almost never raise it: the vast majority of failures print to stderr. A few paths, such as CreateSubjectParam, may raise it indirectly.

AttributeDescription
messagePrimary error message.
additionalAdditional detail; defaults to an empty string.

str(exc) returns message, and when additional is present it concatenates them as message + ' ' + additional.

from viconnexusapi.ViconNexus import ViconNexusException

try:
    vicon.SetSubjectActive('Nobody', True)
except ViconNexusException as exc:
    print('SDK error:', exc.message, exc.additional)

GenerateErrorsproperty (default True)Control

Controls whether the underlying ResultString() is printed to stderr when the low-level call returns Error(). You can temporarily disable it during batch automation to reduce noise, but you must validate results yourself. 

vicon.GenerateErrors = False
try:
    vicon.SetSubjectActive('Nobody', True)   # fails silently
finally:
    vicon.GenerateErrors = True
Recommended error-handling pattern Disable printing → call → immediately read back and validate (for example HasTrajectory, GetModelOutputNames) → record the failures. The return values themselves carry no error state.

ClientpropertyControl

The underlying ViconNexusClient instance. Commands that the facade does not wrap (for example GetCommandList, ProcessRequest, AllocString) can be reached directly here; return values are raw Output_* objects. See low-level client. 

raw = vicon.Client.GetCommandInfo('GetTrajectory')
print(raw.ResultString().Value())
