Quick start

Three steps: install the packages → confirm Nexus is running → connect and read or write data. Everything happens on a Windows command line; no compiler toolchain is needed.

Prerequisites

ItemRequirement
Operating systemWindows x64 (both the .pyd / .dll are 64-bit pre-built binaries)
Nexus2.12 (the version these docs cover); it must be running, and loading a trial first is recommended
Python2.7 or 3.x, and its bitness must match the .pyd (64-bit)
Optional dependenciesnumpy, six (needed only by viconnexusutils)
Version alignment The client DLL and the Nexus version have to match. Using the 2.12 viconnexusapi to connect to a Nexus from another major version usually fails during Connect or returns Error(). You can confirm the version at runtime with GetServerInfo().

Installation

Option 1: run the official batch files

Double-click them in the SDK root directory, or run them from a command line:

install_vicon_nexus_api.bat     :: install the core API (pip install .\viconnexusapi)
install_vicon_nexus_utils.bat   :: install the optional utils package

Each batch file is just a single pip install that installs the local directory into the site-packages of the current Python.

Option 2: install manually with pip

:: core API
pip install "C:\path\to\ViconNexus2.12_PythonSDK\viconnexusapi"

:: optional: numpy wrapper layer
pip install "C:\path\to\ViconNexus2.12_PythonSDK\viconnexusutils"

Both packages provide a setup.py, so they can be installed straight from their source directories. viconnexusutils declares dependencies on six, numpy and viconnexusapi.

Option 3: no install, just add the path

If you do not want to touch the environment (for a script running inside Nexus, for example), simply add the package directory to sys.path:

import sys
sys.path.insert(0, r'C:\path\to\ViconNexus2.12_PythonSDK\viconnexusapi')

from viconnexusapi import ViconNexus
vicon = ViconNexus.ViconNexus()
About "no extra software to install" The packages depend only on the Python standard library (plus numpy/six for the utils). There is no C++ extension to compile: pip install only copies files and never downloads other components from the network.

Verifying the installation

python -c "import viconnexusapi, sys; print(viconnexusapi.__file__); print(sys.version)"

If the package path is printed, the installation succeeded. Note that viconnexusapi/__init__.py is an empty file, so what you actually import are the submodules: 

from viconnexusapi import ViconNexus, ViconUtils
from viconnexusapi import NexusForcePlate, NexusEyeTracker

Connecting and disconnecting

from viconnexusapi import ViconNexus

vicon = ViconNexus.ViconNexus()          # default host='localhost'
# vicon = ViconNexus.ViconNexus('10.0.0.5')   # connect to Nexus on the given host

if not vicon.IsConnected():
    raise RuntimeError('Nexus is not connected')

print(vicon.GetServerInfo())
vicon.Disconnect()
ScenarioSymptom / handling
Nexus is not runningThe constructor raises IOError: Unable to connect to Nexus
Nexus closes after connectingIsConnected() turns False and later calls report errors to stderr
Network hiccupCall Connect() to reconnect; there is no need to rebuild the object
Long batch jobsUse try/finally to guarantee Disconnect()

Your first script

Read the trial summary and one marker trajectory, then compute a midpoint model output:

from viconnexusapi import ViconNexus

vicon = ViconNexus.ViconNexus()
try:
    path, name = vicon.GetTrialName()
    print('Trial:', name, 'in', path)

    subjects = vicon.GetSubjectNames()
    subject = subjects[0]

    markers = vicon.GetMarkerNames(subject)
    print('Markers:', markers)

    x, y, z, e = vicon.GetTrajectory(subject, markers[0])
    valid = [i for i, ok in enumerate(e) if ok]
    print('frames with data:', len(valid), 'of', len(e))

    # create a "modeled marker" and write the midpoint of the two markers into it
    out_name = 'MyMidpoint'
    vicon.CreateModeledMarker(subject, out_name)

    ax, ay, az, ae = vicon.GetTrajectory(subject, 'RKNE')
    bx, by, bz, be = vicon.GetTrajectory(subject, 'RANK')

    data, exists = vicon.GetModelOutput(subject, out_name)
    for i in range(vicon.GetFrameCount()):
        if ae[i] and be[i]:
            exists[i] = True
            data[0][i] = (ax[i] + bx[i]) / 2.0
            data[1][i] = (ay[i] + by[i]) / 2.0
            data[2][i] = (az[i] + bz[i]) / 2.0
        else:
            exists[i] = False

    vicon.SetModelOutput(subject, out_name, data, exists)
finally:
    vicon.Disconnect()
Remember to save The Set* family only changes the trial in memory. To persist your writes you have to call vicon.SaveTrial(30) (which is not allowed from a script running inside Nexus).

Data model cheat sheet

What you readReturn shape
Marker trajectory (all frames)four equal-length lists x, y, z, e; e is a bool
Marker trajectory (single frame)four scalars x, y, z, e
Model output (all frames)components, e; components is an N×M nested list (N components, M frames)
Model output (single frame)components, e; components is a list of length N
Device channelschannelData, ready, rate; sample count = frames × samples per frame
Eventstwo equal-length lists frames, offsets

All missing data is marked with e (exists) instead of dropping the position. Some Set* methods convert NaN to exists=False automatically before writing; see SetTrajectory.

Two runtime environments

EnvironmentWhat you can doLimitations
External Python process the full API, including OpenTrial / SaveTrial / CloseTrial / RunPipeline (this is what batch automation relies on) Nexus must be running and reachable
Script inside Nexus data reads and writes, events, model outputs and so on cannot open or save trials, cannot run pipelines; blocking operations may freeze the UI
