Data types

The SDK has just two “plain data classes”, and GetDeviceDetails() fills both of them. They have no methods, only attributes; every field is initialised to 0 or an empty string on construction.

NexusForcePlate

viconnexusapi.NexusForcePlate.NexusForcePlate — the geometry of a force plate.

AttributeTypeLengthDescription
LocalRlist[float]9Local rotation matrix, flattened in row-major order.
LocalTlist[float]3Local translation relative to the device origin (mm).
WorldRlist[float]9Rotation matrix in world coordinates, flattened row-major.
WorldTlist[float]3Translation in world coordinates (mm).
LowerBoundslist[float]3Lower bound of the plate extent (mm), in the local coordinate frame.
UpperBoundslist[float]3Upper bound of the plate extent (mm), in the local coordinate frame.
Contextstr—Context label that Nexus attaches to this plate (for example Left/Right); may be an empty string — treat it as an opaque string.
 
name, dtype, rate, out_ids, plate, et = vicon.GetDeviceDetails(device_id)

# plate centre (local)
center = [(plate.UpperBounds[i] + plate.LowerBounds[i]) / 2.0 for i in range(3)]

# plate centre (world)
center_global = ViconUtils.Globalise(center, plate.WorldR, plate.WorldT)

# plate size
size = [plate.UpperBounds[i] - plate.LowerBounds[i] for i in range(3)]
The mixed-unit trap LocalR/WorldR/WorldT are in mm; but the raw values of the CoP channels (Cx/Cy/Cz) may be in m, so you need ×1000 before you can compare them with LowerBounds/UpperBounds. The official DetectFootEvents example does exactly that inverse conversion with / 1000.0.

NexusEyeTracker

viconnexusapi.NexusEyeTracker.NexusEyeTracker — the mounting and offset information of an eye tracker.

AttributeTypeLengthDescription
SubjectNamestr—Name of the subject the eye tracker is associated with (may be empty).
SegmentNamestr—Name of the segment the eye tracker is associated with (may be empty).
EyePoseTlist[float]3Eye pose translation (mm).
EyePoseRlist[float]9Eye pose rotation matrix, flattened row-major.
Offsetlist[float]3Eye offset (mm).
 
name, dtype, rate, out_ids, plate, et = vicon.GetDeviceDetails(device_id)
if dtype == 'EyeTracker':
    print('attached to', et.SubjectName, '/', et.SegmentName)
    gaze_origin = ViconUtils.Globalise(et.Offset, et.EyePoseR, et.EyePoseT)

Relationship to ViconNexus methods

Source methodObject produced
GetDeviceDetails5th element → NexusForcePlate; 6th element → NexusEyeTracker

Both objects always exist, whatever the device type: for a force plate device the eyetracker field is an all-zero empty shell, and vice versa. Test the type with the device_type string.
