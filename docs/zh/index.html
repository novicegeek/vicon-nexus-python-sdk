这是什么

Vicon Nexus 自带一套 Python SDK，用于在外部 Python 进程或 Nexus 内部脚本环境中 访问当前加载的试次（trial）。SDK 由两个可安装包组成：

包版本作用
viconnexusapi 1.0.3 核心 API。ViconNexus 门面类、ViconUtils 数学与建模工具、 以及 SWIG 生成的底层客户端 NexusClient / NexusClient3。
viconnexusutils 1.0.0 可选的高层封装：NexusTrajectory、NexusAngles、 NexusSegment，依赖 numpy 与 six。

两个包都以 Windows 预编译二进制（.pyd / .dll）形式分发， 不需要本地 C++ 编译环境；但也因此只能在 Windows x64 上运行。

30 秒上手

确认 Nexus 已启动并加载了一个试次，然后： 

from viconnexusapi import ViconNexus

vicon = ViconNexus.ViconNexus()          # 连接 localhost 上正在运行的 Nexus
try:
    print(vicon.GetServerInfo())          # ('Nexus', 2, 12, ...)
    print(vicon.GetTrialName())           # ('C:\\...\\Walking 2', 'Walking 2')
    print(vicon.GetSubjectNames())        # ['Colin']
    print(vicon.GetFrameCount(), vicon.GetFrameRate())

    x, y, z, e = vicon.GetTrajectory('Colin', 'C7')
    print(x[0], y[0], z[0], e[0])
finally:
    vicon.Disconnect()
要点 构造 ViconNexus() 就等于建立连接；连不上会直接抛 IOError("Unable to connect to Nexus")。多数读写接口不会抛异常， 而是把错误信息打印到 stderr，具体行为见 GenerateErrors。

已知限制

  • 仅 Windows x64。SDK 依赖 ViconSDKClientCPP.dll、_NexusClient3.pyd 等预编译二进制。
  • 必须已有 Nexus 进程。SDK 是客户端，不自带数据层；OpenTrial 等命令也由宿主应用执行。
  • 脚本环境有差别。在 Nexus 内部运行的脚本不能调用 OpenTrial / SaveTrial / CloseTrial / RunPipeline。
  • 错误处理偏“安静”。大部分方法返回 None，失败只打印到 stderr，需自行校验读回值。
  • 部分 utils 方法未完成。见 已知问题。
