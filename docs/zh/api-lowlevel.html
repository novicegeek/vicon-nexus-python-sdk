底层客户端

viconnexusapi.NexusClient3（Python 3）与 viconnexusapi.NexusClient（Python 2） 是 SWIG 4.0.2 自动生成的绑定层，直接映射 C++ 的 ViconNexusClient。 除非门面层缺少某个功能，否则不要直接使用：返回的是 Output_* 对象、字符串是 SafeString、列表是 C++ 容器。

自动生成，勿手改 文件头写明 “Do not make changes to this file unless you know what you are doing—modify the SWIG interface file instead”。 升级 SDK 时这两个文件会被整体覆盖。

ViconNexusClient

与门面层同名的方法一一对应（少数只在底层暴露）。所有方法返回 Output_* 对象，除 IsConnected 等少数返回原始 bool。 

from viconnexusapi import NexusClient3

raw = NexusClient3.ViconNexusClient()
raw.Connect(b'localhost')
print(raw.IsConnected())

info = raw.GetServerInfo()            # Output_GetServerInfo
print(info.Error(), info.MajorVersion, info.MinorVersion)

raw.Disconnect()

参数命名 底层形参带 Hungarian 前缀：i_rSubjectName（输入引用字符串）、 i_FrameNumber（输入值）、i_bForce（输入 bool）。 i_ = input，r = reference。门面层已经把这些名字换成了可读的形式。

通用命令通道

Nexus 的命令协议是“命令名 + 参数表”。这三个方法把协议本身暴露出来， 可以在不发新版 SDK 的情况下调用宿主支持的新命令。

GetCommandList()读

枚举宿主当前支持的全部命令名。

返回 Output_GetCommandList，其 CommandNames 为 vectorss（字符串向量）。

res = raw.GetCommandList()
for i in range(res.CommandNames.size()):
    print(res.CommandNames[i].Value())

GetCommandInfo(i_rCommandName)读

查询单条命令的签名：参数列表及每个参数的类型/名称。

返回 Output_GetCommandInfo，含 Type_Parameter 序列。

info = raw.GetCommandInfo(b'GetTrajectory')
print(info.Error(), info.ResultString().Value())

ProcessRequest(i_rCommandName, i_rInputParameters)写

按名字执行任意命令，参数以 Type_Parameter 列表传入。门面层的每个方法本质上都是它的特化。

返回 Output_ProcessRequest。

适合做什么 探测新版本 Nexus 增加的命令；或在门面层尚未包装某功能时先应急使用。 注意参数需要按 GetCommandInfo 声明的顺序与类型构造。

# 手工构造模型输出数据（门面层替你做的事）
from viconnexusapi import NexusClient3 as nc

data = nc.map_ui_vd()
for component_index in range(3):
    values = nc.vectord()
    for frame in range(120):
        values.push_back(0.0)
    data[component_index] = values

exists = nc.vectorb()
for frame in range(120):
    exists.push_back(True)

raw.SetModelOutput(b'Colin', b'MyOutput', data, exists)
门面层为什么需要 AllocString C++ 接口的“字符串数组”参数要的是 vectorss，元素必须是 SafeString 而不是 Python str。所以 CreateModelOutput 会逐个 AllocString()， 见 调用链。

内部与调试方法

方法用途
AutoNumberCameras()让宿主重新自动编号相机。门面层未包装；现场排查相机识别问题时可能用到。
Crash(i_CrashId, i_bMainThread)故意让宿主崩溃，用于测试 Nexus 的崩溃上报/恢复。生产脚本中绝不要调用。
AllocString(text)把 Python 字符串转成 SafeString。

Python 2 版本差异

NexusClient.py 是同一套接口的 Python 2 绑定（对应 _NexusClient.pyd）， 方法名相同。差异主要在字符串：Python 2 下 str 就是 bytes， 因此门面层只在 sys.version_info < (3, 0) 时对 AllocString 的入参做 encode('utf-8')。
