数据类型

SDK 只有两个“纯数据类”，都由 GetDeviceDetails() 填充。它们没有方法，只有属性；构造时全部初始化为 0 或空串。

NexusForcePlate

viconnexusapi.NexusForcePlate.NexusForcePlate —— 测力台的几何信息。

属性类型长度说明
LocalRlist[float]9局部旋转矩阵，行主序压平。
LocalTlist[float]3相对设备原点的局部平移（mm）。
WorldRlist[float]9世界坐标系旋转矩阵，行主序压平。
WorldTlist[float]3世界坐标平移（mm）。
LowerBoundslist[float]3台面范围下界（mm），局部坐标系。
UpperBoundslist[float]3台面范围上界（mm），局部坐标系。
Contextstr—Nexus 为该台标注的上下文标签（如 Left/Right），可能为空串；按不透明字符串处理。
 
name, dtype, rate, out_ids, plate, et = vicon.GetDeviceDetails(device_id)

# 台面中心（局部）
center = [(plate.UpperBounds[i] + plate.LowerBounds[i]) / 2.0 for i in range(3)]

# 台面中心（世界）
center_global = ViconUtils.Globalise(center, plate.WorldR, plate.WorldT)

# 台面尺寸
size = [plate.UpperBounds[i] - plate.LowerBounds[i] for i in range(3)]
单位混用的坑 LocalR/WorldR/WorldT 是 mm；但 CoP 通道（Cx/Cy/Cz） 的原始数值可能是 m，需要 ×1000 才能和 LowerBounds/UpperBounds 比较。 官方 DetectFootEvents 示例里就显式做了 / 1000.0 的反向换算。

NexusEyeTracker

viconnexusapi.NexusEyeTracker.NexusEyeTracker —— 眼动仪的挂载与偏移信息。

属性类型长度说明
SubjectNamestr—眼动仪所关联的受试者名（可为空）。
SegmentNamestr—眼动仪所关联的骨骼段名（可为空）。
EyePoseTlist[float]3眼位姿平移（mm）。
EyePoseRlist[float]9眼位姿旋转矩阵，行主序压平。
Offsetlist[float]3眼偏移（mm）。
 
name, dtype, rate, out_ids, plate, et = vicon.GetDeviceDetails(device_id)
if dtype == 'EyeTracker':
    print('挂在', et.SubjectName, '/', et.SegmentName)
    gaze_origin = ViconUtils.Globalise(et.Offset, et.EyePoseR, et.EyePoseT)

与 ViconNexus 方法的关系

来源方法产出的对象
GetDeviceDetails第 5 个元素 → NexusForcePlate；第 6 个元素 → NexusEyeTracker

这两个对象总是存在，与设备类型无关：测力台设备的 eyetracker 字段是一个全零的空壳，反之亦然。判类型请用 device_type 字符串。

底层相关类型

如果你直接操作 vicon.Client，还会遇到 ForcePlate、 EyeTracker、Output_*、SafeString 等 SWIG 类型， 见 底层客户端。
