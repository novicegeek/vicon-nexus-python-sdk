ViconNexus

viconnexusapi.ViconNexus.ViconNexus — SDK 的主入口类。 实例化即连接 Nexus，随后通过方法读写试次数据。 

from viconnexusapi import ViconNexus

vicon = ViconNexus.ViconNexus()        # host 默认 'localhost'
vicon.GenerateErrors = True            # 默认 True：失败时把原因打到 stderr

连接与会话

__init__(host='localhost')控制

构造函数。创建底层 ViconNexusClient 并立即尝试连接宿主应用。

参数类型说明
hoststrNexus 所在主机名或 IP，默认本机。

返回 实例。异常 连接失败抛 IOError("Unable to connect to Nexus")。副作用 设置 self.GenerateErrors = True。

vicon = ViconNexus.ViconNexus()
# 连不上时：
# IOError: Unable to connect to Nexus

Connect(host='localhost')控制

若当前未连接则重新连接；已连接时什么也不做。用于网络闪断后的恢复，无需重建对象。

参数类型说明
hoststr要连接的主机，仅在未连接时生效。

返回 None。异常 重连失败抛 IOError。

if not vicon.IsConnected():
    vicon.Connect()

Disconnect()控制

断开与宿主应用的连接。已断开时是空操作。

vicon.Disconnect()

IsConnected()读

查询当前是否与宿主保持连接。

返回 bool。

vicon.IsConnected()   # True / False

GetServerInfo()读

返回所连接服务器（宿主）的版本信息，可用于校验 SDK 与 Nexus 的版本是否匹配。

返回 (program, major, minor, point, release_type) —— program 为程序名（str），major/minor/point 为 int 版本号， release_type 为发行类型字符串（str）。

program, major, minor, point, rel = vicon.GetServerInfo()
if (major, minor) != (2, 12):
    print('版本不匹配:', program, major, minor, point, rel)

试次与帧

GetFrameCount()读

已加载试次的总帧数。

返回 int。

n = vicon.GetFrameCount()

GetFrameRate()读

试次的基础（光学）采样率。

返回 float，单位 Hz。

rate = vicon.GetFrameRate()      # 例如 100.0

GetTrialRange()读

试次的可更新帧范围（可以安全写入的首末帧）。批量写入前用它限制循环区间。

返回 (start_frame, end_frame) —— 两个 int，帧号从 1 开始。

start, end = vicon.GetTrialRange()
for frame in range(start, end + 1):
    pass

GetTrialRegionOfInterest()读

用户在 Nexus 中设置的感兴趣区间（ROI）首末帧。

返回 (start_frame, end_frame) —— 两个 int。

SetTrialRegionOfInterest(startFrame, EndFrame)写

设置用户 ROI 的首末帧。注意第二个形参在源码中是大写开头的 EndFrame，用关键字传参时必须照抄大小写。

参数类型说明
startFrameint区间起始帧（含），从 1 开始。
EndFrameint区间结束帧（含）。
 
vicon.SetTrialRegionOfInterest(10, 250)

GetTrialName()读

当前试次的名称与所在目录。

返回 (path, name) —— path 是磁盘目录（不含文件名），name 是试次名。

path, name = vicon.GetTrialName()
out_file = path + '\\' + name + '.MyOutput.csv'

受试者

GetSubjectNames()读

返回当前已加载的全部受试者名称。

返回 list[str]，可能为空列表（试次中无受试者）。

for subject in vicon.GetSubjectNames():
    print(subject)

GetSubjectInfo()读

一次性拿到受试者的名称、所用模板（model template）与激活状态。

返回 (names, templates, active) —— 三个等长列表： names/templates 为 list[str]，active 为 list[bool]。

for name, tpl, is_active in zip(*vicon.GetSubjectInfo()):
    print('{0} / 模板 {1} / 激活 {2}'.format(name, tpl, is_active))

SetSubjectActive(subjectName, activeState)写

按名称设置受试者的激活状态；'Exclusive' 表示只激活该受试者、关闭其余全部。

参数类型说明
subjectNamestr已存在的受试者名称。
activeStatebool / int / strTrue/False、1/0，或字符串 '1'/'0'/'Exclusive'。其它类型抛 TypeError。
 
subjects = vicon.GetSubjectNames()
for s in subjects:
    vicon.SetSubjectActive(s, True)         # 全部激活
vicon.SetSubjectActive(subjects[0], 'Exclusive')   # 只留第一个

未标注轨迹

未标注（unlabeled）轨迹是重建后尚未指派给受试者标记点的点簇。索引与顺序由 Nexus 决定， 不同试次之间不稳定，因此不要在两次加载之间缓存索引。

GetUnlabeledCount()读

未标注轨迹数量。

返回 int。

n = vicon.GetUnlabeledCount()

GetUnlabeled(index)读

按索引读取一条未标注轨迹的全部帧。

参数类型说明
indexint轨迹索引，取值 0 … GetUnlabeledCount()-1。

返回 (x, y, z, e) —— 三个 list[float]（mm）与一个 list[bool]。

x, y, z, e = vicon.GetUnlabeled(0)
if e[49]:
    print('第 50 帧:', x[49], y[49], z[49])

标记点与轨迹

轨迹数据统一是“四条等长列表”：x / y / z 是坐标（单位 mm）， e 是该帧是否存在有效数据。列表长度等于 GetFrameCount()。

GetMarkerNames(subject)读

受试者身上定义的标记点名称列表（含未采集到数据的标记点）。

参数类型说明
subjectstr已存在的受试者名称。

返回 list[str]。

markers = vicon.GetMarkerNames('Colin')

HasTrajectory(subject, marker)读

判断该标记点是否关联了轨迹数据（标记点可以存在但完全没有轨迹）。

返回 bool。

if vicon.HasTrajectory('Colin', 'C7'):
    print(vicon.GetTrajectory('Colin', 'C7')[0][0])

GetTrajectory(subject, marker)读

读取指定标记点全部帧的轨迹数据。

参数类型说明
subjectstr受试者名称。
markerstr标记点名称。

返回 (x, y, z, e) —— list[float] ×3 与 list[bool]，长度 = 帧数。

x, y, z, e = vicon.GetTrajectory('Colin', 'C7')
exists_count = sum(e)
print('有效帧:', exists_count, '/', len(e))

SetTrajectory(subject, marker, x, y, z, e)写

写入该标记点全部帧的轨迹数据。

若某一帧的 x/y/z 任一为 NaN，SDK 会把该帧的坐标清零并把 e[i] 改成 False 再写入（即在传输层自动“补洞”），因此传入的列表会被就地修改。

参数类型说明
subjectstr受试者名称。
markerstr标记点名称。
x, y, zlist[float]坐标（mm），长度必须等于帧数。
elist[bool]逐帧存在性；False 表示该帧无数据（缺口）。
 
frames = vicon.GetFrameCount()
vicon.SetTrajectory('Colin', 'C7', [0.0] * frames, [0.0] * frames,
                    [0.0] * frames, [True] * frames)

GetTrajectoryAtFrame(subject, marker, frame)读

读取单帧轨迹数据（逐帧循环时比读整条更省内存，但往返次数更多）。

参数类型说明
subjectstr受试者名称。
markerstr标记点名称。
frameint时间条上显示的帧号，从 1 开始。

返回 (x, y, z, e) —— 三个 float 与一个 bool。

x, y, z, e = vicon.GetTrajectoryAtFrame('Colin', 'C7', 50)

SetTrajectoryAtFrame(subject, marker, frame, x, y, z, e)写

写入单帧轨迹。任一坐标为 NaN 时自动置 e=False 且坐标清零。

参数类型说明
frameint帧号，从 1 开始。
x, y, zfloat坐标（mm）。
ebool该帧是否存在数据。
 
# 在第 50 帧制造一个缺口
vicon.SetTrajectoryAtFrame('Colin', 'C7', 50, 0.0, 0.0, 0.0, False)

# 逐帧填充时，注意性能：大批量请改用 SetTrajectory
for frame in range(start, end + 1):
    vicon.SetTrajectoryAtFrame('Colin', 'C7', frame, x, y, z, True)

骨骼段与关节

骨骼段（segment）构成受试者的层级骨架，根段的父节点名为 'World'。 关节（joint）连接两个相邻段。这一段 API 只读，写入骨骼请通过 模型输出（例如 Plug-in Gait Bones 分组）。

GetSegmentNames(subject)读

受试者的骨骼段名称列表。

返回 list[str]。

segments = vicon.GetSegmentNames('Colin')

GetRootSegment(subject)读

返回根骨骼段名称（通常是骨盆）。

返回 str。

root = vicon.GetRootSegment('Colin')
parent, children, markers = vicon.GetSegmentDetails('Colin', root)
print('根段父节点:', parent)     # 'World'

GetSegmentDetails(subject, segment)读

骨骼段的层级与关联信息。

参数类型说明
subjectstr受试者名称。
segmentstr该受试者已存在的骨骼段名称。

返回 (parent, children, markers) —— parent 为父段名（根段为 'World'）， children 为 list[str] 子段名， markers 为 list[str] 该段关联的标记点名。

parent, children, markers = vicon.GetSegmentDetails('Colin', 'LHip')
for child in children:
    print(child)

GetJointNames(subject)读

受试者的关节名称列表。

返回 list[str]。

GetJointDetails(subject, joint)读

关节两侧的骨骼段名称。

参数类型说明
subjectstr受试者名称。
jointstr该受试者已存在的关节名称。

返回 (parent, child) —— 两个 str。

joints = vicon.GetJointNames('Colin')
parent, child = vicon.GetJointDetails('Colin', joints[0])
print('{0}: {1} - {2}'.format(joints[0], parent, child))

模型输出

模型输出（model output）是 Nexus 里承载“计算结果”的通用容器：角度、力、力矩、功率、 Plug-in Gait 骨骼、以及建模标记点都是模型输出。每个输出有一个分组名 （如 Angles、Forces、Plug-in Gait Bones、Modeled Markers）， 以及若干“分量”，每个分量再带一个量纲。

合法量纲（Quantity Type）说明
Length Mass Angle Acceleration Angular Acceleration Angular Velocity Frequency Force ForceNormalized Torque TorqueNormalized Power PowerNormalized Pressure Electric Potential Velocity 大小写敏感，传入其它字符串会失败（错误打到 stderr）

GetModelOutputNames(subject)读

受试者全部模型输出的名称。

返回 list[str]。

outputs = vicon.GetModelOutputNames('Colin')

GetModelOutputDetails(subject, modelOutputName)读

模型输出的分组、分量名与各分量量纲，可用于“照抄”创建一个结构相同的新输出。

返回 (group, components, types) —— group 为分组名（str），components 与 types 为等长的 list[str]。

group, comps, types = vicon.GetModelOutputDetails('Colin', 'LeftHipAngle')
vicon.CreateModelOutput('Colin', 'MyCopy', group, comps, types)

GetModelOutput(subject, modelOutputName)读

读取模型输出全部帧的数据。

返回 (components, e) —— components 是 N×M 嵌套列表（N = 分量数，M = 帧数）， e 是长度 M 的 list[bool] 逐帧存在性。 缺失帧的数值不保证有意义，请先用 e 过滤。

data, exists = vicon.GetModelOutput('Colin', 'LeftHipAngle')
n_components = len(data)        # 例如 3（X/Y/Z）
n_frames = len(data[0])         # 等于 GetFrameCount()
# 第 2 个分量在第 50 帧的值
print(data[1][49], exists[49])

SetModelOutput(subject, modelOutputName, components, e)写

写入模型输出全部帧的数据。

内部会把 NaN 替换为 0，并把对应帧的 exists 置为 False； 同时也做了 numpy.bool_ → bool 的兼容转换，因此传 numpy 数组也安全。

参数类型说明
componentslist[list[float]]N×M 矩阵，行是分量、列是帧。
elist[bool]长度 M 的逐帧存在性。
 
data, exists = vicon.GetModelOutput('Colin', 'LeftHipAngle')
vicon.SetModelOutput('Colin', 'MyCopy', data, exists)

# 全部置零
frames = vicon.GetFrameCount()
vicon.SetModelOutput('Colin', 'MyCopy', [[0.0] * frames for _ in range(3)],
                     [True] * frames)

GetModelOutputAtFrame(subject, modelOutputName, frame)读

读取单帧的模型输出分量值。

返回 (components, e) —— components 为长度 N 的 list[float]，e 为 bool。

comps, ok = vicon.GetModelOutputAtFrame('Colin', 'LeftHipAngle', 50)

SetModelOutputAtFrame(subject, modelOutputName, frame, components, e)写

写入单帧模型输出。任一分量为 NaN 时整帧置为不存在并把分量清零。

参数类型说明
frameint帧号，从 1 开始。
componentslist[float]长度必须等于该输出的分量数。
ebool该帧是否存在数据。
 
comps, ok = vicon.GetModelOutputAtFrame('Colin', 'LeftHipAngle', 50)
comps = [c + 100.0 for c in comps]
vicon.SetModelOutputAtFrame('Colin', 'LeftHipAngle', 50, comps, True)

CreateModelOutput(subject, modelOutputName, groupName, componentNames, QuantityTypes)写

新建一个模型输出（此时还没有数据），之后用 SetModelOutput / SetModelOutputAtFrame 填数据。名称在受试者内必须唯一。

参数类型说明
groupNamestr分组名，决定在 Nexus 树中的归类，可自定义。
componentNameslist[str]分量名，长度即分量数。
QuantityTypeslist[str]每个分量的量纲，取值见上表，长度需与分量数一致。
 
names = ['RX', 'RY', 'RZ', 'TX', 'TY', 'TZ', 'SX', 'SY', 'SZ']
types = ['Angle', 'Angle', 'Angle',
         'Length', 'Length', 'Length',
         'Length', 'Length', 'Length']
vicon.CreateModelOutput('Colin', 'HED', 'Plug-in Gait Bones', names, types)
完整 Gait 输出 需要一次性创建 Plug-in Gait 全套输出时，直接用 ViconUtils.CreateViconGaitModelOutputs。

CreateModeledMarker(subject, modelOutputName)写

新建一个“建模标记点”：本质是分组为 Modeled Markers、 分量为 X/Y/Z、量纲为 Length 的模型输出。 它既能在工作区立体显示，也能像点一样被读取，常用于中点、虚拟标记点、几何派生点。

返回 None。之后用 GetModelOutput 拿 N×M 数据写入。

vicon.CreateModeledMarker('Colin', 'MyMidpoint')

ax, ay, az, ae = vicon.GetTrajectory('Colin', 'RKNE')
bx, by, bz, be = vicon.GetTrajectory('Colin', 'RANK')

data, exists = vicon.GetModelOutput('Colin', 'MyMidpoint')
for i in range(vicon.GetFrameCount()):
    if ae[i] and be[i]:
        exists[i] = True
        data[0][i] = (ax[i] + bx[i]) / 2.0
        data[1][i] = (ay[i] + by[i]) / 2.0
        data[2][i] = (az[i] + bz[i]) / 2.0
    else:
        exists[i] = False
vicon.SetModelOutput('Colin', 'MyMidpoint', data, exists)

受试者参数与分析参数

Nexus 里有两类“标量参数”，都挂在受试者上：

  • 受试者参数（subject parameter）：静态量，如身高、体重、腿长。有单位、默认值、“是否必填”属性。
  • 分析参数（analysis parameter）：分析过程中产生的量，可随时读写。

受试者参数

GetSubjectParamNames(subject)读

受试者全部静态参数的名称。

返回 list[str]。

params = vicon.GetSubjectParamNames('Colin')

GetSubjectParamDetails(subject, param)读

一次性取参数的当前值、单位、默认值、是否必填、是否有值。

返回 5 元组 (value, unit, default, required, hasvalue) —— value/default 为 float，unit 为 str， required/hasvalue 为 bool。

value, unit, default, required, hasvalue = \
    vicon.GetSubjectParamDetails('Colin', 'Height')
print('{0} [{1}] 默认 {2}  必填={3} 有值={4}'.format(
    value, unit, default, required, hasvalue))
文档字符串有误 源码 GetSubjectParamDetails 的 docstring 示例只解包了 4 个变量， 实际返回 5 个。以上面代码为准。

GetSubjectParam(subject, param)读

只取参数值与“是否有值”标志。

返回 (value, hasvalue) —— float 与 bool。

value, hasvalue = vicon.GetSubjectParam('Colin', 'Height')

SetSubjectParam(subject, param, value, bForce=False)写

写入参数值。bForce=True 时强制写入（用于覆盖必填参数等受限情形）。

参数类型说明
valuefloat新值。
bForcebool是否强制写入，默认 False。
 
value, _ = vicon.GetSubjectParam('Colin', 'Height')
vicon.SetSubjectParam('Colin', 'Height', value * 1.01, True)

CreateSubjectParam(subject, param, value, unit, default, required)写

新建静态参数，名称在受试者内必须唯一。

参数类型说明
valuefloat初始值。
unitstr单位。仅支持 'none'、'mm'、'deg'、'kg'、's'。
defaultfloat默认值。
requiredbool是否为必填参数。
 
vicon.CreateSubjectParam('Colin', 'MyParam', 1.23, 'mm', 0.0, False)

params = vicon.GetAnalysisParamNames('Colin')

参数的当前值、单位与“是否有值”标志。

返回 3 元组 (value, unit, hasvalue) —— float、str、bool。

value, unit, hasvalue = vicon.GetAnalysisParamDetails('Colin', 'MyParam')
文档字符串有误 源码示例写的是 value, unit, default, required = ...（4 个）， 实际只返回 3 个。

写入分析参数值。

CreateAnalysisParam(subject, param, value, unit)写

新建分析参数，名称在受试者内必须唯一。

事件

事件是“帧号 + 帧内偏移”的标注，例如足跟着地/离地。它由三元组定位： 受试者 + 上下文（context）+ 事件类型（event）。

字段合法取值（大小写敏感）
contextLeft、Right、General
eventFoot Strike、Foot Off、General
offset帧内偏移（秒），范围 0.0 … 1/FrameRate

GetEvents(subject, context, event)读

查询匹配指定受试者、上下文、事件类型的全部事件。

返回 (frames, offsets) —— list[int] 与 list[float]，等长；无匹配时是两个空列表。

frames, offsets = vicon.GetEvents('Colin', 'Left', 'Foot Strike')
for f, off in zip(frames, offsets):
    print('帧 {0} + {1:.4f}s'.format(f, off))

CreateAnEvent(subject, context, event, frame, offset)写

在 frame + offset 处创建一个事件。

参数类型说明
contextstrLeft / Right / General。
eventstrFoot Strike / Foot Off / General。
frameint帧号，从 1 开始。
offsetfloat帧内偏移秒数，通常 < 1/FrameRate。
 
vicon.ClearAllEvents()
vicon.CreateAnEvent('Colin', 'Left', 'Foot Strike', 137, 0.0)
vicon.CreateAnEvent('Colin', 'Left', 'Foot Off', 190, 0.006)
参数顺序坑 源码 docstring 的示例把 context 和 event 写反了 （vicon.CreateAnEvent('Patricia', 'Foot Strike', 'Left', ...)）。 正确顺序是 subject, context, event，见上面的代码。

ClearAllEvents()写

删除当前试次中的全部事件（所有受试者、所有上下文）。不可撤销，且不影响已保存到磁盘的旧文件。

vicon.ClearAllEvents()

模拟设备

测力台、眼动仪、模拟采集卡在 SDK 里统称 device。层级是三层： 

DeviceID  ──▶  DeviceOutputID  ──▶  ChannelID
（一块测力台）    （Force / CoP / Moment）   （Fx / Fy / Fz …）

通信一律用 ID，名称只是可选的便利标签，且大小写敏感。 设备采样率可以与试次帧率不同：若设备更快，一帧会对应多个采样，采样顺序为 frame1[s1], frame1[s2], … frameN[sN]。

GetDeviceIDs()读

试次中全部模拟设备的 ID 列表。

返回 list[int]（无符号整数）。

for device_id in vicon.GetDeviceIDs():
    print(device_id, vicon.GetDeviceDetails(device_id)[:3])

GetDeviceNames()读

已命名设备的名称列表（未命名的设备不在其中）。

返回 list[str]。

GetDeviceIDFromName(name)读

按设备名反查设备 ID。

参数类型说明
namestr已命名设备的名称，大小写敏感。

返回 设备 ID（整数）。名称不存在时返回 0/无效值，不会抛异常。

plate_id = vicon.GetDeviceIDFromName('MyForcePlate')

GetDeviceDetails(deviceID)读

设备级信息，并对测力台/眼动仪附带几何与位姿数据。

返回 6 元组 (name, device_type, rate, deviceOutputIDs, forceplate, eyetracker)：

元素类型说明
namestr设备名，可能为空串。
device_typestr'ForcePlate' / 'EyeTracker' / 'Other'。
ratefloat设备采样率（Hz）。
deviceOutputIDslist[int]该设备的输出 ID 列表。
forceplateNexusForcePlate总是返回对象；只有测力台才有意义。
eyetrackerNexusEyeTracker总是返回对象；只有眼动仪才有意义。
 
name, dtype, rate, out_ids, plate, et = vicon.GetDeviceDetails(1)
if dtype == 'ForcePlate':
    print('台面中心 X:', (plate.UpperBounds[0] + plate.LowerBounds[0]) / 2.0)
    print('世界坐标平移:', plate.WorldT)

GetDeviceOutputIDFromName(deviceID, name)读

在指定设备下按输出名查输出 ID。测力台常见输出名：'Force'、'CoP'、'Moment'。

返回 输出 ID（整数）。

force_out = vicon.GetDeviceOutputIDFromName(plate_id, 'Force')

GetDeviceOutputDetails(deviceID, deviceOutputID)读

输出级信息：名称、类型、单位、就绪状态、通道名与通道 ID。

返回 6 元组 (name, output_type, unit, ready, channelNames, channelIDs) —— ready 为 bool，channelNames 为 list[str]， channelIDs 为 list[int]。

name, otype, unit, ready, ch_names, ch_ids = \
    vicon.GetDeviceOutputDetails(plate_id, force_out)
if not ready:
    print('输出未就绪，数据不可用')

GetDeviceChannelIDFromName(deviceID, deviceOutputID, name)读

在指定输出下按通道名查通道 ID。测力台 Force 输出常见通道：'Fx'、'Fy'、'Fz'；CoP 输出：'Cx'、'Cy'、'Cz'。

返回 通道 ID（整数）。

fx_id = vicon.GetDeviceChannelIDFromName(plate_id, force_out, 'Fx')

设备通道数据

六个读取方法按两个维度组合：局部 / 全局坐标，以及 整条 / 单帧 / “按光学帧对齐”。

坐标系整条单帧（采样帧号）单光学帧（对齐）
局部（相对设备） GetDeviceChannel GetDeviceChannelAtFrame GetDeviceChannelForFrame
全局（世界坐标） GetDeviceChannelGlobal GetDeviceChannelGlobalAtFrame GetDeviceChannelGlobalForFrame
AtFrame 与 ForFrame 的区别 …AtFrame 用设备采样帧索引；…ForFrame 用 光学帧索引，返回与该光学帧对应的那组采样。做力学分析、要和标记点对齐时用 Global + ForFrame。

GetDeviceChannel(deviceID, deviceOutputID, channelID)读

读取整条通道（局部坐标）。

返回 (channelData, ready, rate) —— channelData 为 list[float]，长度 = 帧数 × 每帧采样数； ready 为 bool；rate 为 float（Hz）。

data, ready, rate = vicon.GetDeviceChannel(plate_id, force_out, fx_id)

GetDeviceChannelAtFrame(deviceID, deviceOutputID, channelID, frame)读

按设备采样帧号读取该帧的全部采样。

返回 (channelData, ready, rate) —— channelData 长度 = 每帧采样数。

samples, ready, rate = vicon.GetDeviceChannelAtFrame(plate_id, force_out, fx_id, 200)

GetDeviceChannelForFrame(deviceID, deviceOutputID, channelID, frame)读

按光学帧读取与该帧对应的采样数据。

返回 (channelData, ready, rate)。

# 与标记点同一时间基准
samples, ready, rate = vicon.GetDeviceChannelForFrame(plate_id, force_out, fx_id, 200)

GetDeviceChannelGlobal(deviceID, deviceOutputID, channelID)读

读取整条通道，并把坐标/方向转到世界坐标系。力、力矩、CoP 用这个才有物理意义。

返回 (channelData, ready, rate)。

fz, ready, rate = vicon.GetDeviceChannelGlobal(plate_id, force_out, fz_id)

GetDeviceChannelGlobalAtFrame(deviceID, deviceOutputID, channelID, frame)读

按设备采样帧号读取全局坐标下的采样。

返回 (channelData, ready, rate)。

GetDeviceChannelGlobalForFrame(deviceID, deviceOutputID, channelID, frame)读

按光学帧读取全局坐标下的采样。

返回 (channelData, ready, rate)。

SetDeviceChannel(deviceID, deviceOutputID, channelID, channelData)写

写入整条通道数据。推荐用这个方法批量修改，比逐帧调用快得多。

原始采集里被标记为“缺失”的帧不可写：读出来是 0，写回去会被忽略，但 channelData 的长度仍必须覆盖全部采样。

参数类型说明
channelDatalist[float]长度 = 帧数 × 每帧采样数。
 
import math

for device_id in vicon.GetDeviceIDs():
    name, dtype, rate, out_ids, plate, et = vicon.GetDeviceDetails(device_id)
    if dtype != 'ForcePlate':
        continue
    force_out = vicon.GetDeviceOutputIDFromName(device_id, 'Force')
    _, _, _, _, _, ch = vicon.GetDeviceOutputDetails(device_id, force_out)
    fx = vicon.GetDeviceChannel(device_id, force_out, ch[0])[0]
    fy = vicon.GetDeviceChannel(device_id, force_out, ch[1])[0]
    fz = vicon.GetDeviceChannel(device_id, force_out, ch[2])[0]

    # 小于 25 N 视为噪声，置零
    mag = [math.sqrt(a * a + b * b + c * c) for a, b, c in zip(fx, fy, fz)]
    for i, m in enumerate(mag):
        if m < 25.0:
            fx[i] = fy[i] = fz[i] = 0.0

    vicon.SetDeviceChannel(device_id, force_out, ch[0], fx)
    vicon.SetDeviceChannel(device_id, force_out, ch[1], fy)
    vicon.SetDeviceChannel(device_id, force_out, ch[2], fz)

SetDeviceChannelAtFrame(deviceID, deviceOutputID, channelID, frame, channelData)写

写入单帧的单通道采样（长度为每帧采样数）。

性能 源码明确提示：逐帧调用可能显著慢于一次 SetDeviceChannel。 批量修改请优先用整条写入。 
fx, _, _ = vicon.GetDeviceChannelAtFrame(plate_id, force_out, fx_id, 200)
fx = [v / 2.0 for v in fx]
vicon.SetDeviceChannelAtFrame(plate_id, force_out, fx_id, 200, fx)

样条

样条接口用于对离散轨迹做平滑求导：先把有效散点提交给样条对象，再按需取 1 阶（速度） 或 2 阶（加速度）导数。一个 ViconNexus 实例只有一个样条对象， 后一次提交会覆盖前一次。

SubmitSplineTrajectory(frames, xData, yData, zData, frameRate)写

用散点初始化（或重新初始化）样条对象。只提交有效点： 带缺口的帧会破坏拟合，应先按 e 过滤。

参数类型说明
frameslist[int]散点对应的帧号（从 1 开始）。
xData, yData, zDatalist[float]坐标（mm），长度与 frames 一致。
frameRatefloat数据帧率（Hz），用于换算导数的时间基。
 
frame_rate = vicon.GetFrameRate()
start, end = vicon.GetTrialRange()
frames = list(range(start, end + 1))

x, y, z, e = vicon.GetTrajectory('Colin', 'LKNE')
valid = [i for i, ok in enumerate(e) if ok]

vicon.SubmitSplineTrajectory(
    [frames[i] for i in valid],
    [x[i] for i in valid],
    [y[i] for i in valid],
    [z[i] for i in valid],
    frame_rate)

vx, vy, vz = vicon.GetSplineResults(1)      # 速度
ax, ay, az = vicon.GetSplineResults(2)      # 加速度

GetSplineResults(derivative)读

取当前样条对象的指定阶导数。

参数类型说明
derivativeint导数阶数，1 = 速度，2 = 加速度。

返回 (x, y, z) —— 三个 list[float]，长度与提交的散点数一致。

文档字符串有误 GetSplineResults 的 docstring 把 frames/x/y/z/frameRate 又列了一遍（从 SubmitSplineTrajectory 复制而来），实际只有一个参数 derivative。

试次操作

这四个方法让外部 Python 进程充当“遥控器”驱动 Nexus。 它们不能在 Nexus 内部脚本中调用，否则会死锁或直接失败。

RunPipeline(pipeline, location, timeout)宿主

运行 Nexus 的 Processing Pipeline。若已有 pipeline 在运行，本次调用会失败。

参数类型说明
pipelinestr已存在 pipeline 的名称。
locationstrpipeline 位置：'Private'、'Shared'、'System'；传空串 '' 走默认搜索。
timeoutint客户端等待秒数。超时只让客户端提前返回，宿主的 pipeline 仍会继续跑。
 
vicon.RunPipeline('Reconstruct', '', 45)
vicon.RunPipeline('MyLabeling', 'Private', 120)

OpenTrial(trial, timeout)宿主

在宿主中打开试次。失败条件：pipeline 正在运行、处于 live 模式、 找不到对应 .ENF 文件、或宿主当前禁止打开。

参数类型说明
trialstr试次的绝对路径，不含扩展名。
timeoutint客户端等待秒数。
 
vicon.CloseTrial(30)
vicon.OpenTrial(r'C:\Users\Public\Documents\Vicon\Nexus Sample Data'
                r'\Colin\Walking Trials\Walking 2', 30)
未保存数据会弹窗 如果当前试次有未保存修改，宿主要求保存的对话框会阻塞自动化。 批处理前先 SaveTrial() 或 CloseTrial()。

SaveTrial(timeout)宿主

把当前试次保存到磁盘。pipeline 运行中或 live 模式下会失败。

参数类型说明
timeoutint客户端等待秒数。
 
vicon.SaveTrial(30)

CloseTrial(timeout)宿主

关闭当前试次，不保存。pipeline 运行中或 live 模式下会失败。

参数类型说明
timeoutint客户端等待秒数。
 
vicon.CloseTrial(30)

异常与开关

ViconNexusException(message, additional='')异常

viconnexusapi.ViconNexus.ViconNexusException，继承自 Exception。 设计上用于表达 SDK 错误，但当前 1.0.3 版本的公开方法几乎不抛它： 绝大多数失败是打印到 stderr。CreateSubjectParam 等少数路径可能间接抛出。

属性说明
message主错误信息。
additional附加说明，默认空串。

str(exc) 返回 message， 有 additional 时拼成 message + ' ' + additional。

from viconnexusapi.ViconNexus import ViconNexusException

try:
    vicon.SetSubjectActive('Nobody', True)
except ViconNexusException as exc:
    print('SDK 错误:', exc.message, exc.additional)

GenerateErrors属性（默认 True）控制

控制底层返回 Error() 时是否把 ResultString() 打印到 stderr。批量自动化时可临时关掉以减少噪音，但要自己校验结果。 

vicon.GenerateErrors = False
try:
    vicon.SetSubjectActive('Nobody', True)   # 静默失败
finally:
    vicon.GenerateErrors = True
推荐的错误处理套路 关掉打印 → 调用 → 立即读回校验（例如 HasTrajectory、GetModelOutputNames） → 记录失败项。因为返回值本身不携带错误状态。

Client属性控制

底层 ViconNexusClient 实例。门面层没包装的命令（例如 GetCommandList、ProcessRequest、AllocString） 可以从这里直达，返回值是原始 Output_* 对象。 见 底层客户端。 

raw = vicon.Client.GetCommandInfo('GetTrajectory')
print(raw.ResultString().Value())
