快速开始

三步走：装包 → 确认 Nexus 在跑 → 连上去读写数据。 全程只需要 Windows 命令行，不需要编译工具链。

前置条件

项目要求
操作系统Windows x64（.pyd / .dll 均为 64 位预编译）
Nexus2.12（本文档对应版本），需正在运行，且建议先加载一个试次
Python2.7 或 3.x，必须与 .pyd 位数一致（64 位）
可选依赖numpy、six（仅 viconnexusutils 需要）
版本对齐 客户端 DLL 与 Nexus 版本需要匹配。用 2.12 的 viconnexusapi 连接其它大版本 Nexus 通常会在 Connect 阶段失败或返回 Error()。版本号可用 GetServerInfo() 在运行时确认。

安装

方式一：运行官方批处理

在 SDK 根目录双击或命令行执行：

install_vicon_nexus_api.bat     :: 安装核心 API（pip install .\viconnexusapi）
install_vicon_nexus_utils.bat   :: 安装可选的 utils 包

批处理内部就是一条 pip install，把本地目录装进当前 Python 的 site-packages。

方式二：手动 pip 安装

:: 核心 API
pip install "C:\path\to\ViconNexus2.12_PythonSDK\viconnexusapi"

:: 可选：numpy 封装层
pip install "C:\path\to\ViconNexus2.12_PythonSDK\viconnexusutils"

两个包都提供了 setup.py，可以直接从源码目录安装。viconnexusutils 会声明依赖 six、numpy、viconnexusapi。

方式三：不安装，直接挂路径

如果不想污染环境（例如给 Nexus 内部脚本用），把包目录加到 sys.path 即可：

import sys
sys.path.insert(0, r'C:\path\to\ViconNexus2.12_PythonSDK\viconnexusapi')

from viconnexusapi import ViconNexus
vicon = ViconNexus.ViconNexus()
关于“不用另装软件” 这两个包的总依赖只有 Python 标准库（外加 utils 的 numpy/six）。没有需要编译的 C++ 扩展， pip install 只做文件拷贝，不会联网下载其它组件。

验证安装

python -c "import viconnexusapi, sys; print(viconnexusapi.__file__); print(sys.version)"

能打印出包路径即为安装成功。注意 viconnexusapi/__init__.py 是空文件， 所以真正要导入的是子模块： 

from viconnexusapi import ViconNexus, ViconUtils
from viconnexusapi import NexusForcePlate, NexusEyeTracker

连接与断开

from viconnexusapi import ViconNexus

vicon = ViconNexus.ViconNexus()          # 默认 host='localhost'
# vicon = ViconNexus.ViconNexus('10.0.0.5')   # 连接指定主机上的 Nexus

if not vicon.IsConnected():
    raise RuntimeError('Nexus 未连接')

print(vicon.GetServerInfo())
vicon.Disconnect()
场景现象 / 处理
Nexus 没启动构造函数抛 IOError: Unable to connect to Nexus
连上后 Nexus 关闭IsConnected() 变 False，后续调用报错到 stderr
网络抖动调用 Connect() 重连，无需重建对象
长时间批量作业建议 try/finally 保证 Disconnect()

第一个脚本

读取试次概况与某个标记点轨迹，并计算一个中点模型输出：

from viconnexusapi import ViconNexus

vicon = ViconNexus.ViconNexus()
try:
    path, name = vicon.GetTrialName()
    print('Trial:', name, 'in', path)

    subjects = vicon.GetSubjectNames()
    subject = subjects[0]

    markers = vicon.GetMarkerNames(subject)
    print('Markers:', markers)

    x, y, z, e = vicon.GetTrajectory(subject, markers[0])
    valid = [i for i, ok in enumerate(e) if ok]
    print('frames with data:', len(valid), 'of', len(e))

    # 新建一个“建模标记点”，写入两标记点中点
    out_name = 'MyMidpoint'
    vicon.CreateModeledMarker(subject, out_name)

    ax, ay, az, ae = vicon.GetTrajectory(subject, 'RKNE')
    bx, by, bz, be = vicon.GetTrajectory(subject, 'RANK')

    data, exists = vicon.GetModelOutput(subject, out_name)
    for i in range(vicon.GetFrameCount()):
        if ae[i] and be[i]:
            exists[i] = True
            data[0][i] = (ax[i] + bx[i]) / 2.0
            data[1][i] = (ay[i] + by[i]) / 2.0
            data[2][i] = (az[i] + bz[i]) / 2.0
        else:
            exists[i] = False

    vicon.SetModelOutput(subject, out_name, data, exists)
finally:
    vicon.Disconnect()
记得保存 Set* 系列只改内存中的试次。写完要落盘需调用 vicon.SaveTrial(30)（且不能在 Nexus 内部脚本中调用）。

数据模型速记

读取对象返回值形状
标记点轨迹（全部帧）x, y, z, e 四个等长列表，e 是 bool
标记点轨迹（单帧）x, y, z, e 四个标量
模型输出（全部帧）components, e；components 是 N×M 嵌套列表（N 分量、M 帧）
模型输出（单帧）components, e；components 是长度 N 的列表
设备通道channelData, ready, rate；采样数 = 帧数 × 每帧采样数
事件frames, offsets 两个等长列表

所有缺失数据用 e（exists）标记，而不是丢弃位置。部分 Set* 方法会 把 NaN 自动转成 exists=False 再写入，见 SetTrajectory。

两种运行环境

环境能做什么限制
外部 Python 进程 全部 API，包括 OpenTrial / SaveTrial / CloseTrial / RunPipeline（自动化批处理就靠它） 需要 Nexus 已运行并可连
Nexus 内部脚本 数据读写、事件、模型输出等 不能控制试次打开/保存，不能运行 Pipeline；阻塞式操作可能卡住 UI
