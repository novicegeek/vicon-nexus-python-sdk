viconnexusutils

独立分发的可选包（1.0.0），把 SDK 的“列表元组”封装成基于 numpy 的对象： 轨迹、角度、骨骼段。对象内部用 (帧数, 3) 或 (帧数, 9) 的 ndarray 存储，Read() / Write() 负责与 Nexus 之间搬运。

需要 numpy 需要 six 帧号从 1 开始 部分方法未完成
先看这个：与新版 numpy 不兼容 包内使用了 np.long 与 np.bool，这两个别名在 numpy 1.24 起已被移除， 调用相关方法（Position(frames)、Read()、AngleBetween 等） 会抛 AttributeError: module 'numpy' has no attribute 'long'。 请把环境钉在 numpy<1.24，或自行把源码里的 np.long → int、np.bool → bool 替换掉。

数据模型

类内部数组含义
NexusTrajectory(M, 3)三维点集：每个元素是一个位置（mm）。
NexusAngles(M, 3)角度三元组（代码里按角轴存储，单位沿用 Nexus 的度）。
NexusSegment(M, 3) ×3骨骼段：平移、欧拉角朝向、缩放各一组。

M 是帧数。缺失数据统一用 NaN 表示，Write() 时 含 NaN 的帧会被置为 exists=False。

NexusObject

viconnexusutils.NexusObject.NexusObject —— 抽象基类，规定三个契约方法。

subject_name属性读写

对象所属受试者名。构造时可传，之后可改。对象在读写时会用它定位数据。

traj = NexusTrajectory.NexusTrajectory('Colin')
traj.subject_name = 'Patricia'

Create(name, SDK)抽象

在 Nexus 中创建一个空输出（若已存在则跳过）。由子类实现。

Read(name, SDK)抽象

从 Nexus 读入指定名称的输出，填充到对象内部数组（NaN 表示缺失帧）。

Write(name, SDK)抽象

把对象内部数组写回 Nexus 的同名输出。帧数不足时按单帧复制/补 NaN， 超过试次帧数则抛 ValueError('Too many output points for trial')。

Read / Write 都要求 SDK 是 ViconNexus.ViconNexus 实例，否则抛 TypeError； 找不到同名输出抛 ValueError。

NexusTrajectory

viconnexusutils.NexusTrajectory.NexusTrajectory(subject_name=None)

方法说明
Create(name, SDK)若不存在则调用 CreateModeledMarker 建一个建模标记点。
Read(name, SDK)名称是标记点则读 GetTrajectory，是模型输出则读 GetModelOutput，两者皆非抛 ValueError。
Write(name, SDK)经 SetModelOutput 写回（所以目标必须是模型输出，不能是原始标记点）。
Position(frames=None)取位置。
SetPosition(components, frames=None)设位置。
mean()按帧平均，返回新的 NexusTrajectory。
+ - * /、mean逐元素运算，详见下方运算符表。

Position(frames=None)读

读取位置数据。

参数类型说明
framesNone / int / arrayNone 取全部；标量取该帧（1 基，内部做 frames-1）；数组取多帧。

返回 嵌套 list（全部帧时为 M×3；单帧时为长度 3 的 numpy 行向量，不是普通 list）。

traj = NexusTrajectory.NexusTrajectory('Colin')
traj.Read('LKNE', vicon)
print(traj.Position()[0])      # 第 1 帧
print(traj.Position(50))       # 第 50 帧

SetPosition(components, frames=None)写

设置位置数据。components 必须是 N×3；frames 给定时只更新指定帧，且长度必须与 components 行数一致，否则抛 ValueError。

traj.SetPosition([[0.0, 0.0, 0.0]] * 10)          # 全部帧
traj.SetPosition([[1.0, 2.0, 3.0]], [50])          # 只改第 50 帧
实现缺陷 按帧写入后用于“向后扩展数组”的 np.append(...) 返回值被丢弃， 因此不会真正扩展数组长度。需要变长时请一次传入完整数组。

运算符

表达式结果
traj + traj2 / + 数组逐元素相加，返回新轨迹。受试者名按“相同则保留、一方为空则取另一方、冲突则置空”合并。
traj - traj2逐元素相减。
traj * 标量 / 标量 * traj缩放。
traj / 标量缩放。
traj * segment把点从段坐标系转到全局（调用 segment.GlobalisePoint）。
traj / segment把全局点转到段坐标系（调用 segment.LocalisePoint）。
-traj / +traj取反 / 复制。
 
# 段局部坐标 → 世界坐标，写法很直观
world_points = local_points * segment

NexusAngles

viconnexusutils.NexusAngles.NexusAngles(subject_name=None)

方法说明
Create(name, SDK)创建分组为 Angles、分量 X/Y/Z、量纲 Angle 的模型输出。
Read(name, SDK)读取同名模型输出，缺失帧置 NaN。
Write(name, SDK)写回模型输出。
Angles(frames)取角度（语义同 Position）。注意 frames 是必填参数。
SetAngles(components, frames=None)设角度。
* / 、-、+对角度值做缩放/取反。
mean()有缺陷，见下。
已知缺陷（1.0.0）
  • Read() 里用 angles[~e, :] = np.nan，其中 angles 形状是 (3, M) 而 e 长度是 M，帧数大于 3 时掩码维度不匹配， 会抛 IndexError。建议直接用 ViconNexus.GetModelOutput 后自行置 NaN。
  • mean() 把结果写进了 result._position（本类没有这个属性）， 返回值里的角度仍是初始的 NaN。需要均值请自己 np.mean。
  • Angles() 没有默认参数，传 None 才表示“全部帧”。

NexusSegment

viconnexusutils.NexusSegment.NexusSegment(subject=None, axisOrder='xyz') —— 一个带位置、朝向、缩放的骨骼段。

global_segment()静态构造

返回位于原点、单位旋转、缩放为 1 的“世界段”，可用作坐标变换的起点。

world = NexusSegment.NexusSegment.global_segment()

axisOrder属性读写

欧拉角轴序，默认 'xyz'。setter 会校验必须同时包含 x、y、z，否则抛 ValueError('Invalid axis order…')。

方法说明
Create(name, SDK)创建 Plug-in Gait Bones 分组、9 分量（RX RY RZ TX TY TZ SX SY SZ）的模型输出。
Read(name, SDK)读 9 分量：前 3 个是角轴（度）→ 转角轴矩阵 → 欧拉角；后 3 个平移；再 3 个缩放。
Write(name, SDK)欧拉角 → 矩阵 → 角轴（度）后写回 9 分量。
Populate(origin, firstAxis, crossingAxis, axisOrder=None)由三条轨迹构造段。
Position(frames=None) / SetPosition(...)平移。
Orientation(frames=None) / SetOrientation(...)朝向（欧拉角，弧度）。
Scale(frames=None) / SetScale(...)缩放（Scale() 有缺陷，见下）。
GlobalisePoint(point, frames=None)段内点 → 全局。
LocalisePoint(point, frames=None)全局点 → 段内。
TranslatePointInSegment(point, translation, frames=None)段内平移一个点。
AngleBetween(segment, angle_type='euler', order='xyz')两段夹角。
+ - （与轨迹）把段原点按轨迹平移。

Populate(origin, firstAxis, crossingAxis, axisOrder=None)写

用三条轨迹定义一个骨骼段：origin 给原点， firstAxis 给主轴的方向与长度，crossingAxis 与主轴叉乘给出第二轴的平面。 主轴模长同时作为段的缩放。

参数类型说明
originNexusTrajectory / N×3段原点轨迹。
firstAxisNexusTrajectory / N×3指向主轴的向量（相对原点）。
crossingAxisNexusTrajectory / N×3定义第二轴所在平面的向量。
axisOrderstr可选；缺省用对象当前 axisOrder。

返回 None。三个输入长度必须一致，否则抛 ValueError('Mismatched sizes…')；形状不是 N×3 抛 TypeError。

seg = NexusSegment.NexusSegment('Colin')

pelvis = NexusTrajectory.NexusTrajectory('Colin');  pelvis.Read('PEL', vicon)
sacrum = NexusTrajectory.NexusTrajectory('Colin');  sacrum.Read('SACR', vicon)
lhip   = NexusTrajectory.NexusTrajectory('Colin');  lhip.Read('LHIP', vicon)

seg.Populate(pelvis, sacrum - pelvis, lhip - pelvis)
seg.Create('MySeg', vicon)
seg.Write('MySeg', vicon)

GlobalisePoint(point, frames=None)读

把段局部坐标下的点转到全局坐标，逐帧使用该帧的位姿。

返回 list（M×3）；point 可以是 NexusTrajectory 或 N×3 列表，长度 1 时自动广播到所有帧。

knee_global = seg.GlobalisePoint([[0.0, 0.0, 40.0]])

LocalisePoint(point, frames=None)读

把全局点转到段局部坐标。

返回 list（M×3）。

TranslatePointInSegment(point, translation, frames=None)读

把点按段坐标系内的向量 translation 平移，返回全局坐标的 NexusTrajectory。用于“从某点沿骨段方向偏移一段距离”。

# 从踝点沿小腿段向上 100 mm
offset_traj = seg.TranslatePointInSegment(ankle, [0.0, 0.0, 100.0])

AngleBetween(segment, angle_type='euler', order='xyz')读

计算本段与另一段之间的相对朝向，返回 NexusAngles。两个段帧数不同时， 单帧的一方会被广播；都不为 1 且不相等则抛 ValueError('Incompatible segments…')。

参数类型说明
segmentNexusSegment与之比较的段，其它类型抛 TypeError。
angle_typestr'euler'（默认，度）、'fixed'（度，取转置后取负）、'helical'（角轴，弧度）。
orderstr欧拉轴序，默认 'xyz'。

返回 NexusAngles，受试者名按合并规则设置。

rel = thigh.AngleBetween(shank, 'euler', 'xyz')
rel.Write('MyKneeAngle', vicon)
helical 与其它两种单位不同 'euler'/'fixed' 乘了 180/π（度）， 'helical' 没有（弧度）。混用前先统一单位。

已知问题汇总

位置现象规避
np.long / np.boolnumpy ≥ 1.24 抛 AttributeError钉 numpy<1.24 或替换别名
NexusAngles.Read帧数 > 3 时布尔掩码维度不匹配改用 GetModelOutput
NexusAngles.mean写入不存在的 _position，结果全 NaN自行 np.mean
NexusSegment.Scale返回的是 _orientation直接读内部 _scale 或自己维护
NexusSegment.mean末尾 pass，返回 None不使用
NexusSegment.__rmul__直接 pass，返回 None写成 traj * seg，别写 seg * traj
NexusTrajectory.SetPosition按帧写入不会扩展数组一次性传入完整数组
Write 的补帧逻辑frames+1: 切片会跳过一帧保持对象帧数与试次一致
NexusSegment.SetPosition/SetOrientation/SetScale帧索引未做 -1，与 Position 等不一致（0 基）传入时自己减 1，或整段替换

典型工作流

from viconnexusapi import ViconNexus
from viconnexusutils import NexusTrajectory, NexusSegment

vicon = ViconNexus.ViconNexus()

# 1. 读三个标记点
pelvis = NexusTrajectory.NexusTrajectory('Colin'); pelvis.Read('PEL', vicon)
lhip   = NexusTrajectory.NexusTrajectory('Colin'); lhip.Read('LHIP', vicon)
rhip   = NexusTrajectory.NexusTrajectory('Colin'); rhip.Read('RHIP', vicon)

# 2. 构造骨盆段（原点 PEL，主轴指 LHIP，第三点定平面）
seg = NexusSegment.NexusSegment('Colin')
seg.Populate(pelvis, lhip - pelvis, rhip - pelvis)

# 3. 写回成一个 9 分量模型输出
seg.Create('MyPelvis', vicon)
seg.Write('MyPelvis', vicon)

# 4. 落盘（仅在外部 Python 进程中可行）
vicon.SaveTrial(30)
