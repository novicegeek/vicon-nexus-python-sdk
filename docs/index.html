What this is

Vicon Nexus ships a Python SDK for reaching the currently loaded trial, either from an external Python process or from a script running inside Nexus. The SDK is distributed as two installable packages:

PackageVersionRole
viconnexusapi 1.0.3 Core API. The ViconNexus facade, the ViconUtils math and modelling helpers, and the SWIG-generated clients NexusClient / NexusClient3.
viconnexusutils 1.0.0 Optional higher-level wrappers: NexusTrajectory, NexusAngles, NexusSegment. Depends on numpy and six.

Both packages ship as pre-built Windows binaries (.pyd / .dll), so no local C++ toolchain is required — but that also means they only run on Windows x64.

30-second start

Make sure Nexus is running with a trial loaded, then: 

from viconnexusapi import ViconNexus

vicon = ViconNexus.ViconNexus()          # connect to Nexus on localhost
try:
    print(vicon.GetServerInfo())          # ('Nexus', 2, 12, ...)
    print(vicon.GetTrialName())           # ('C:\\...\\Walking 2', 'Walking 2')
    print(vicon.GetSubjectNames())        # ['Colin']
    print(vicon.GetFrameCount(), vicon.GetFrameRate())

    x, y, z, e = vicon.GetTrajectory('Colin', 'C7')
    print(x[0], y[0], z[0], e[0])
finally:
    vicon.Disconnect()
Key point Constructing ViconNexus() is connecting. If it cannot reach Nexus it raises IOError("Unable to connect to Nexus"). Most read/write calls do not raise; they print the failure reason to stderr instead — see GenerateErrors.

Known limitations

  • Windows x64 only. The SDK depends on pre-built binaries such as ViconSDKClientCPP.dll and _NexusClient3.pyd.
  • Nexus must already be running. The SDK is a client with no data layer of its own; even OpenTrial is executed by the host application.
  • Script context matters. Scripts running inside Nexus cannot call OpenTrial / SaveTrial / CloseTrial / RunPipeline.
  • Quiet error handling. Most methods return None on failure and only print to stderr, so verify by reading back.
  • Some utils methods are unfinished. See known issues.

Conventions

read
Reads data, never modifies the trial
write
Modifies trial data in Nexus memory (save to persist)
host
Needs the host application; not callable from inside Nexus

Types in the signatures come from the source docstrings and implementation. frame always means "the frame number shown on the application time bar" and is 1-based; list indices are 0-based.
