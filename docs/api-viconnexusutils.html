viconnexusutils

An optional, separately distributed package (1.0.0) that wraps the SDK's “list of tuples” into numpy-backed objects: trajectories, angles and bone segments. Objects store their data internally in (frames, 3) or (frames, 9) ndarrays, and Read() / Write() move that data to and from Nexus.

Requires numpy Requires six Frame numbers are 1-based Some methods are unfinished
Read this first: incompatible with newer numpy The package uses np.long and np.bool; both aliases were removed in numpy 1.24, so calling the affected methods (Position(frames), Read(), AngleBetween and others) raises AttributeError: module 'numpy' has no attribute 'long'. Pin your environment to numpy<1.24, or replace np.long → int and np.bool → bool in the source yourself.

Data model

ClassInternal arrayMeaning
NexusTrajectory(M, 3)A set of 3-D points: every element is one position (mm).
NexusAngles(M, 3)An angle triple (stored as angle-axis in the code; units follow Nexus degrees).
NexusSegment(M, 3) ×3A bone segment: one block each for translation, Euler-angle orientation and scale.

M is the frame count. Missing data is always expressed as NaN, and on Write() any frame containing NaN is set to exists=False.

NexusObject

viconnexusutils.NexusObject.NexusObject — abstract base class defining three contract methods.

subject_namepropertyread/write

Name of the subject the object belongs to. It can be passed at construction time and changed afterwards; the object uses it to locate its data when reading and writing.

traj = NexusTrajectory.NexusTrajectory('Colin')
traj.subject_name = 'Patricia'

Create(name, SDK)abstract

Creates an empty output in Nexus (skipped if it already exists). Implemented by subclasses.

Read(name, SDK)abstract

Reads the output with the given name from Nexus into the object's internal array (NaN marks a missing frame).

Write(name, SDK)abstract

Writes the object's internal array back to the like-named output in Nexus. If it holds fewer frames than the trial, values are copied per frame / padded with NaN; if it holds more than the trial's frame count, ValueError('Too many output points for trial') is raised.

Both Read and Write require SDK to be a ViconNexus.ViconNexus instance, otherwise they raise TypeError; if no output of that name can be found they raise ValueError.

Position(frames=None)read

Reads position data.

ParameterTypeDescription
framesNone / int / arrayNone takes all frames; a scalar takes that frame (1-based, with frames-1 applied internally); an array takes several frames.

Returns a nested list (M×3 for all frames; for a single frame a length-3 numpy row vector, not a plain list).

traj = NexusTrajectory.NexusTrajectory('Colin')
traj.Read('LKNE', vicon)
print(traj.Position()[0])      # frame 1
print(traj.Position(50))       # frame 50

SetPosition(components, frames=None)write

Sets position data. components must be N×3; when frames is given only those frames are updated, and its length must match the number of rows in components, otherwise ValueError is raised.

traj.SetPosition([[0.0, 0.0, 0.0]] * 10)          # all frames
traj.SetPosition([[1.0, 2.0, 3.0]], [50])          # change frame 50 only
Implementation flaw The np.append(...) used to “grow the array backwards” after a per-frame write has its return value discarded, so the array length is never actually extended. When you need a longer array, pass the complete array in a single call.

NexusAngles

viconnexusutils.NexusAngles.NexusAngles(subject_name=None)

MethodDescription
Create(name, SDK)Creates a model output with group Angles, components X/Y/Z and quantity Angle.
Read(name, SDK)Reads the like-named model output, marking missing frames as NaN.
Write(name, SDK)Writes the model output back.
Angles(frames)Reads the angles (same semantics as Position). Note that frames is a required argument.
SetAngles(components, frames=None)Sets the angles.
* / , -, +Scale / negate the angle values.
mean()Broken, see below.
Known defects (1.0.0)
  • Read() uses angles[~e, :] = np.nan, where angles has shape (3, M) while e has length M; once there are more than 3 frames the mask dimensions do not match and it raises IndexError. Prefer calling ViconNexus.GetModelOutput directly and setting NaN yourself.
  • mean() writes its result into result._position (this class has no such attribute), so the angles in the returned value are still the initial NaN. If you need a mean, call np.mean yourself.
  • Angles() has no default argument; only None means “all frames”.

NexusSegment

viconnexusutils.NexusSegment.NexusSegment(subject=None, axisOrder='xyz') — a bone segment carrying position, orientation and scale.

global_segment()static constructor

Returns the “world segment”: at the origin, with unit rotation and scale 1, usable as the starting point for coordinate transforms.

world = NexusSegment.NexusSegment.global_segment()

axisOrderpropertyread/write

Euler angle axis order, default 'xyz'. The setter validates that it contains x, y and z, otherwise it raises ValueError('Invalid axis order…').

Populate(origin, firstAxis, crossingAxis, axisOrder=None)write

Defines a bone segment from three trajectories: origin gives the origin, firstAxis gives the primary axis' direction and length, and the cross product of crossingAxis with the primary axis defines the plane of the second axis. The magnitude of the primary axis also serves as the segment's scale.

ParameterTypeDescription
originNexusTrajectory / N×3Trajectory of the segment origin.
firstAxisNexusTrajectory / N×3Vector pointing along the primary axis (relative to the origin).
crossingAxisNexusTrajectory / N×3Vector defining the plane in which the second axis lies.
axisOrderstrOptional; defaults to the object's current axisOrder.

Returns None. All three inputs must have the same length, otherwise ValueError('Mismatched sizes…') is raised; a shape other than N×3 raises TypeError.

seg = NexusSegment.NexusSegment('Colin')

pelvis = NexusTrajectory.NexusTrajectory('Colin');  pelvis.Read('PEL', vicon)
sacrum = NexusTrajectory.NexusTrajectory('Colin');  sacrum.Read('SACR', vicon)
lhip   = NexusTrajectory.NexusTrajectory('Colin');  lhip.Read('LHIP', vicon)

seg.Populate(pelvis, sacrum - pelvis, lhip - pelvis)
seg.Create('MySeg', vicon)
seg.Write('MySeg', vicon)

GlobalisePoint(point, frames=None)read

Transforms points given in segment-local coordinates into global coordinates, using that frame's pose for every frame.

Returns a list (M×3); point may be a NexusTrajectory or an N×3 list, and a length of 1 is automatically broadcast to all frames.

knee_global = seg.GlobalisePoint([[0.0, 0.0, 40.0]])

LocalisePoint(point, frames=None)read

Transforms global points into segment-local coordinates.

Returns a list (M×3).

TranslatePointInSegment(point, translation, frames=None)read

Translates the point by the vector translation expressed in the segment frame, returning a NexusTrajectory in global coordinates. Use it to “offset a point by some distance along the bone segment”.

# 100 mm up the shank segment from the ankle point
offset_traj = seg.TranslatePointInSegment(ankle, [0.0, 0.0, 100.0])

AngleBetween(segment, angle_type='euler', order='xyz')read

Computes the relative orientation between this segment and another one, returning NexusAngles. When the two segments have different frame counts, the single-frame side is broadcast; if neither is 1 and the counts differ, ValueError('Incompatible segments…') is raised.

ParameterTypeDescription
segmentNexusSegmentThe segment to compare against; any other type raises TypeError.
angle_typestr'euler' (default, degrees), 'fixed' (degrees, negated after transposing), 'helical' (angle-axis, radians).
orderstrEuler axis order, default 'xyz'.

Returns a NexusAngles, with its subject name set by the merge rules.

rel = thigh.AngleBetween(shank, 'euler', 'xyz')
rel.Write('MyKneeAngle', vicon)
helical uses different units from the other two 'euler'/'fixed' are multiplied by 180/π (degrees), whereas 'helical' is not (radians). Normalise units before mixing them.

Typical workflow

from viconnexusapi import ViconNexus
from viconnexusutils import NexusTrajectory, NexusSegment

vicon = ViconNexus.ViconNexus()

# 1. Read three markers
pelvis = NexusTrajectory.NexusTrajectory('Colin'); pelvis.Read('PEL', vicon)
lhip   = NexusTrajectory.NexusTrajectory('Colin'); lhip.Read('LHIP', vicon)
rhip   = NexusTrajectory.NexusTrajectory('Colin'); rhip.Read('RHIP', vicon)

# 2. Build the pelvis segment (origin PEL, primary axis towards LHIP, third point fixes the plane)
seg = NexusSegment.NexusSegment('Colin')
seg.Populate(pelvis, lhip - pelvis, rhip - pelvis)

# 3. Write it back as a 9-component model output
seg.Create('MyPelvis', vicon)
seg.Write('MyPelvis', vicon)

# 4. Save to disk (only possible from an external Python process)
vicon.SaveTrial(30)
